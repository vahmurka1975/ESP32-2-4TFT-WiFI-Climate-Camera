# Release Notes — ClimateCamera v1.2.7

## Что нового в версии 1.2.7

1. **Экран-заставка с часами через 1 минуту бездействия энкодера:**
   - При отсутствии вращения или нажатия энкодера в течение **60 секунд** (`CLOCK_SCREEN_TIMEOUT_MS = 60000`) контроллер автоматически переходит в полноэкранный режим часов (`320×240`, без верхней шапки и нижней строки подсказок).
   - Если контроллер находился в режиме меню или редактирования параметра (`UI_EDIT`), несохранённое редактирование безопасно отменяется (`cancelEdit()`), после чего включается заставка.
   - **Крупная индикация времени `ЧЧ:ММ`** по центру экрана семисегментным шрифтом `Font 7` в масштабе `×2` (высота цифр **96 пикселей**) с секундным миганием разделительного двоеточия. До первой синхронизации времени отображается `--:--`.
   - **Нижние капсулы климата:** в нижней части экрана расположены две симметричные карточки с текущими показаниями температуры (`°C`) и влажности (`%`) без текстовых заголовков.
   - **Пробуждение первым касанием:** любой поворот или нажатие энкодера мгновенно возвращает прежний экран без ложного переключения страницы или входа в меню.

2. **Синхронизация точного времени по NTP (`configTzTime`):**
   - При подключении к Wi-Fi роутеру (`WL_CONNECTED`) автоматически запускается синхронизация системных часов ESP32 по протоколу SNTP (`pool.ntp.org`, `time.nist.gov`, `ru.pool.ntp.org`).
   - Часовой пояс настраивается макросом `CC_TZ_INFO` в `NetworkConfig.h` или `Secrets.h` (по умолчанию `"MSK-3"` — Москва `UTC+3`). После первой синхронизации внутренний RTC ESP32 продолжает отсчёт времени даже при временном пропадании интернета.
   - Добавлен HTTP-маршрут `GET /api/time` и поля `time`, `wallClock`, `wallClockValid` в JSON-ответ `GET /api/status`, а также отображение текущего времени в шапке веб-интерфейса.

3. **Драйвер датчика SHT30 и функции v1.2.6:**
   - Сохранён помехоустойчивый программный (bit-bang Open-Drain) драйвер датчика **SHT30** (`Sht30Reliable.h` / `Sht30Reliable.cpp`, адрес `0x44`, `SDA = GPIO 21`, `SCL = GPIO 22`).
   - Полностью сохранены встроенные иконки `FaviconAssets.h`, аварийный режим работы холодильника по таймеру (4 мин работа / 10 мин пауза) при отказе датчика и безопасное обновление Web OTA с выгрузкой буфера дисплея.
