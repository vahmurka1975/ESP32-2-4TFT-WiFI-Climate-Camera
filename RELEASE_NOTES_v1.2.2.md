# Release v1.2.2 — ESP32 Climate Camera (ILI9341 2.4" 320×240)

## Основные изменения
- **Драйвер дисплея:** включён альтернативный набор инициализации `ILI9341_2_DRIVER` для устранения срыва синхронизации («белого шума» / рассыпания строк) на экранах 2.4" TFT SPI 240×320.
- **Коррекция палитры (инверсии цветов):** добавлен макрос `TFT_INVERSION_ON` в `User_Setup.h` и принудительный вызов `tft.invertDisplay(true)` при старте (`initDisplay`) и при перезапуске экрана (`recoverDisplay`).
- **Альбомная ориентация 320×240:** установлена ориентация `DISPLAY_ROTATION = 3`.
- **Обновление версии и Web UI:** версия прошивки поднята до `1.2.2`, в шапке веб-панели и на странице `/ota` указана конфигурация `ILI9341 320×240 · v1.2.2`.
- **Совместимость с Arduino IDE 1.8.19 и PlatformIO:** скетч упакован в папку `ClimateCamera_1_2_2_IDE1819` с одноимённым файлом `ClimateCamera_1_2_2_IDE1819.ino`.
