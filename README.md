# ESP32 Climate Camera v1.2.4 (ILI9341 2.4" 320×240 · Wi-Fi · Remote Monitoring · Web OTA)

Контроллер климатической камеры (вяление, ферментация, сыроделие, созревание) на базе **ESP32 Dev Module** с цветным дисплеем **2.4" TFT SPI ILI9341 (320×240)**, промышленным алгоритмом защиты датчика **SHT30**, ПИ-регулятором оборотов вентилятора (PWM 25 кГц + тахометр), локальным управлением энкодером и защищённым **веб-интерфейсом для локального и удалённого мониторинга через интернет**.

---

## Что нового в версии v1.2.4
* **Поддержка удалённого мониторинга через проброс порта (Port Forwarding / Virtual Servers):**
  * Добавлена настройка статического локального IP-адреса на ESP32 (`CC_USE_STATIC_IP`, `WiFi.config`) для жёсткой привязки к правилу NAT на роутере **TP-Link EC225-G5**.
  * Добавлена учётная запись **«Только мониторинг» (`viewer`)**: позволяет безопасно отслеживать температуру, влажность, обороты вентилятора, состояние реле и скачивать журнал событий из интернета со смартфона, блокируя любые изменения уставок и переключения реле.
  * Добавлена **защита от перебора паролей (Brute-Force Rate Limiting)**: после 5 неудачных попыток входа IP-адрес автоматически блокируется на 60 секунд (HTTP `429`).
  * Добавлены защитные HTTP-заголовки (`X-Frame-Options: DENY`, `X-Content-Type-Options: nosniff`, `Referrer-Policy: no-referrer`).
  * Реализован умный режим резервной точки доступа (`CC_AP_FALLBACK_ONLY`): точка доступа `ClimateCamera-AP` выключается при стабильном соединении с роутером и автоматически включается только при потере связи с роутером дольше 45 секунд.
  * В веб-интерфейсе теперь отображаются уровень сигнала Wi-Fi (`RSSI`, дБм), IP шлюза, MAC-адрес контроллера и индикатор режима `Мониторинг`.

## Основные возможности контроллера

### 1. Климатическая автоматика и защита оборудования (Core 1)
* **Канал охлаждения (Реле IN4 — Компрессор):**
  * Поддержание температуры по гистерезису (`tempTarget ± tempHyst`).
  * Задержка первого пуска после включения питания: **5 минут (300 с)**.
  * Минимальная пауза между циклами компрессора: **5 минут (300 с)**.
  * Минимальное время непрерывного хода: **2 минуты (120 с)**.
  * Максимальное время непрерывной работы (защита от обмерзания): **40 минут (2400 с)**.
* **Канал увлажнения (Реле IN2 — Увлажнитель):**
  * Поддержание влажности по гистерезису (`humTarget ± humHyst`).
  * Импульсный антиконденсационный режим: **20 секунд работы / 120 секунд паузы**.
* **Канал вентиляции (Реле IN1 + PWM 25 кГц + Тахометр):**
  * Циклическая работа по таймеру (`fanWorkMin` / `fanPauseMin`) и автоматическое включение при активном охлаждении или увлажнении.
  * ПИ-регулятор оборотов (`300..1500 RPM`, коэффициенты `pidKp`, `pidKi`).
  * Контроль вращения крыльчатки по датчику Холла (`fanTachFault`).
* **Надёжный опрос датчика SHT30 (`Sht30Reliable`):**
  * Контроль CRC-8, автоматическое восстановление зависшей шины I²C (9 тактов SCL + STOP + Soft Reset).
  * Защита от ложных срабатываний при единичных помехах (до 3 сбоев подряд) и гарантированное аварийное отключение всех реле при потере датчика дольше 7 секунд.

### 2. Экран 2.4" ILI9341 (320×240) и энкодер
* 5 экранов состояния (Главный, Выходы и таймеры, Вентилятор и ШИМ, Уставки, Журнал событий).
* Локальное меню настройки всех параметров с сохранением в энергонезависимую память NVS (с проверкой CRC-32).
* Драйвер `ILI9341_2_DRIVER`, альбомная ориентация `320×240` (`DISPLAY_ROTATION = 3`) и аппаратная коррекция палитры (`invertDisplay(true)`).

## Схема подключения (Распиновка ESP32)

### Дисплей 2.4" TFT SPI ILI9341 (240×320)
| Вывод дисплея | Пин ESP32 | Примечание |
| :--- | :--- | :--- |
| `VCC` | `5V` или `3.3V` | Питание модуля |
| `GND` | `GND` | Общий провод |
| `CS` | **GPIO 19** | Обязателен для 2.4" модуля |
| `RESET / RST` | **GPIO 13** | Аппаратный сброс дисплея |
| `DC / RS` | **GPIO 25** | Команда / Данные |
| `SDI / MOSI` | **GPIO 23** | Шина SPI MOSI |
| `SCK / CLK` | **GPIO 18** | Шина SPI SCLK |
| `LED / BL` | `3.3V` | Подсветка экрана |
| `SDO / MISO` | **Не подключать** | GPIO 19 занят линией `CS` |

### Датчик SHT30, энкодер, вентилятор и модуль реле
| Узел | Пин ESP32 | Назначение |
| :--- | :--- | :--- |
| `SHT30 SDA / SCL` | **GPIO 21 / GPIO 22** | Шина I²C (адрес `0x44`) |
| `Энкодер CLK / DT / SW` | **GPIO 32 / 33 / 4** | Поворот и кнопка энкодера |
| `Вентилятор PWM` | **GPIO 16** | ШИМ 25 кГц управления скоростью |
| `Вентилятор TACH` | **GPIO 27** | Тахометр (2 импульса на оборот) |
| `Реле IN1` | **GPIO 15** | Питание вентилятора |
| `Реле IN2` | **GPIO 17** | Увлажнитель |
| `Реле IN3` | **GPIO 14** | Резерв (всегда выключен) |
| `Реле IN4` | **GPIO 26** | Компрессор холодильника |

## Сборка и загрузка прошивки

### Вариант 1. PlatformIO
В корне архива расположен готовый `platformio.ini`, который автоматически подключает `User_Setup.h` и схему разделов `min_spiffs.csv`:
```bash
pio run -t upload
```

### Вариант 2. Arduino IDE 1.8.19
1. Установите ядро **Arduino-ESP32 `2.0.17`** и библиотеку **TFT_eSPI `2.5.43`**.
2. Скопируйте файл `TFT_eSPI_setup/User_Setup.h` в папку `Documents/Arduino/libraries/TFT_eSPI/User_Setup.h` с заменой.
3. Проверьте настройки сети и пароли в `ClimateCamera_1_2_4_IDE1819/Secrets.h`.
4. Откройте `ClimateCamera_1_2_4_IDE1819/ClimateCamera_1_2_4_IDE1819.ino`.
5. Выберите плату `ESP32 Dev Module` и схему разделов `Minimal SPIFFS (1.9MB APP with OTA/190KB SPIFFS)`.

## Настройка удалённого доступа на роутере TP-Link EC225-G5
Подробная пошаговая инструкция находится в файле **`TP_LINK_EC225_G5_GUIDE.md`** в корне архива:
1. В `Secrets.h` задан статический IP `192.168.0.150` (шлюз `192.168.0.1`).
2. В настройках роутера TP-Link EC225-G5 (**Дополнительные настройки → Сеть → Сервер DHCP → Резервирование адресов**) закрепите IP `192.168.0.150` за MAC-адресом ESP32.
3. В разделе **Дополнительные настройки → Переадресация NAT → Виртуальные серверы** добавьте правило:
   * **Внешний порт:** `8080`
   * **Внутренний IP:** `192.168.0.150`
   * **Внутренний порт:** `80`
   * **Протокол:** `TCP`
4. Откройте из интернета `http://ВАШ_СТАТИЧЕСКИЙ_IP:8080/` и войдите под логином `viewer` (мониторинг) или `admin` (управление).
