# ESP32-Climate-Camera 1.2.1 — ILI9341 SPI 2.4" 320×240

Основа: https://github.com/vahmurka1975/ESP32-Climate-Camera/tree/main/ClimateCamera_1_2_1_IDE1819
Это адаптация исходников, а не официальный релиз автора. FW_VERSION оставлен исходным.

## Что изменено
Драйвер ILI9341 вместо ST7789; физическая матрица 240×320; логический экран 320×240.
Поворот DISPLAY_ROTATION=1 применяется при старте и при восстановлении дисплея.
Добавлен TFT_CS=19. MOSI=23, SCLK=18, DC=25, RST=13 сохранены.
MISO отключён (TFT_MISO=-1): GPIO19 занят CS. SDO/MISO дисплея не подключать.
SPI оставлен 20 МГц. Элементы главной страницы, реле, меню, уставок и журнала растянуты по ширине; значения уставок выровнены справа.
Полосное обновление, 16-битный спрайт и резервный 8-битный режим сохранены.
Буфер 16 бит: 153600 байт без служебных накладных расходов; 8 бит: 76800 байт.
Климатическая логика, NVS, датчик SHT30, энкодер, реле, вентилятор и сеть не редактировались.

## Подключение TFT
| Контакт TFT | ESP32 |
| --- | --- |
| SCK / CLK | GPIO18 |
| SDI / MOSI | GPIO23 |
| CS | GPIO19 |
| DC / RS | GPIO25 |
| RESET / RST | GPIO13 |
| SDO / MISO | Не подключать |
| GND | Общая земля |
Питание и LED/BL — по схеме конкретного модуля. В прошивке новый GPIO для подсветки не назначен.
Логические уровни ESP32 — 3.3 В; питание платы дисплея зависит от наличия её стабилизатора.
Сенсорный контроллер и SD-карта не добавлены.

## Arduino IDE 1.8.19
Откройте ClimateCamera_1_2_1_IDE1819/ClimateCamera_1_2_1_IDE1819.ino.
Плата ESP32 Dev Module, пакет Arduino-ESP32 2.0.17, библиотека TFT_eSPI 2.5.43. Для сохранения Web OTA используйте схему разделов с двумя OTA-слотами (например Minimal SPIFFS). Huge APP без OTA не подходит.
Скопируйте TFT_eSPI_setup/User_Setup.h в каталог установленной библиотеки TFT_eSPI, заменив её User_Setup.h.
В TFT_eSPI/User_Setup_Select.h должен быть активен только #include <User_Setup.h>; другие пользовательские setup отключите.
ВАЖНО: одноимённый файл рядом со скетчем сам по себе не настраивает отдельную компиляцию библиотеки TFT_eSPI.
После изменения настройки библиотеки выполните полную пересборку.
Сетевые реквизиты задавайте так же, как в исходной версии, используя Secrets.example.h; личные данные в адаптацию не добавлялись.
Если экран перевёрнут относительно корпуса, поменяйте DISPLAY_ROTATION с 1 на 3 в ClimateCamera.cpp. Оба положения — альбомные.
Не подключайте TFT CS к земле: он должен управляться GPIO19.

## Проверка
В архиве находится diff для аудита изменений.
Проверены тексты замен, неизменность назначений PIN_*, климатической логики и остальных исходных файлов, кроме двух файлов дисплея.
Компиляция выполнена успешно для ESP32 Dev Module (esp32dev): PlatformIO, espressif32 6.9.0, Arduino-ESP32 2.0.17, TFT_eSPI 2.5.43. Использована таблица разделов min_spiffs.csv. RAM: 68596 из 327680 байт (20.9%); Flash: 964485 из 1966080 байт (49.1%). Динамический буфер экрана не входит в приведённую статическую RAM. На физическом устройстве прошивка не проверялась. Готовых .bin в этом архиве нет. Конфигурация сборки platformio.ini и журнал BUILD_ILI9341.log приложены.
Первую проверку экрана выполняйте с отключёнными силовыми нагрузками.

## PlatformIO
В корне архива приложен platformio.ini с проверенной конфигурацией. Команда сборки: pio run. Настройки TFT передаются всем единицам компиляции через -include и USER_SETUP_LOADED. Это не требует изменения установленной TFT_eSPI. Для Arduino IDE используйте инструкцию выше.
