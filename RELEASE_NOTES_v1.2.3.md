# Release Notes — ESP32 Climate Camera v1.2.3

## Нововведения в v1.2.3
1. **Удалённый мониторинг через проброс порта (NAT / Virtual Servers):**
   * Добавлена поддержка фиксированного локального IP-адреса (`CC_USE_STATIC_IP`, `CC_STATIC_IP`, `CC_STATIC_GATEWAY`, `CC_STATIC_SUBNET`, `CC_STATIC_DNS`).
   * Добавлена учётная запись наблюдателя (`CC_VIEWER_USER` / `CC_VIEWER_PASS`) с режимом «Только мониторинг» (блокировка `POST`-запросов управления и OTA на уровне сервера и интерфейса).
   * Добавлена защита от подбора пароля (блокировка IP на 60 секунд после 5 неудачных попыток авторизации).
   * Добавлен режим `CC_AP_FALLBACK_ONLY`: резервная точка доступа включается только при отсутствии связи с роутером более 45 секунд.
2. **Диагностика сети в Web UI:**
   * Отображение уровня приёма Wi-Fi (`RSSI` в дБм), адреса шлюза и MAC-адреса ESP32.
3. **Документация:**
   * Добавлена подробная инструкция `TP_LINK_EC225_G5_GUIDE.md` для настройки роутера TP-Link EC225-G5 и полный `README.md`.
